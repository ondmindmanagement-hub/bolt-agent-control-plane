# BOLT Agent Control Plane

Hackathon prototype for governed AI-agent execution.

The project demonstrates a small control layer that receives planned agent actions and classifies them as:

- allow
- human approval required
- deny

This public repository contains only the hackathon demo harness, not proprietary BOLT core source.

## Run

npm start
npm test

## Nebius x NVIDIA direction

The next integration step is to connect the control plane to a model endpoint hosted through the hackathon's approved infrastructure, then measure replanning, approval frequency, recovery and traceability under constrained execution.
